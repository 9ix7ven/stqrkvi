STQRKVI × ZERO — Portfolio
==========================

FILES
- index.html          Main page and metadata
- css/style.css       Responsive red/black visual system
- js/main.js          Mobile navigation, scroll progress, reveal animations,
                      profile image fallback, Discord ID copy button
- assets/favicon.svg Site icon
- assets/images/     Optional local profile image backups

DEPLOY
1. Upload the contents of this folder to your website's /portfolio/ directory.
2. Keep the folder structure exactly as provided.
3. Profile photos load from the provided image URLs first. For a self-hosted copy,
   add these optional files in assets/images/: stqrkvi.jpg and zero.jpg.
   Local JPG/JPEG/PNG/WebP backups are automatically tried if remote images fail.
4. If deploying to a case-sensitive host, keep all folder/file names lowercase.

NOTES
- The LTC Vault graphic is a visual project preview; the displayed zero balance is
  decorative and does not represent a real wallet or live balance.
- Project summaries describe work/experiments and do not imply every feature is live.
- The site uses Google Fonts; system fallbacks remain available if fonts are blocked.
- No build step or npm install is required. This is a static HTML/CSS/JS website.
