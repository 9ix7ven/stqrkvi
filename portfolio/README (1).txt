STQRKVI × ZERO — PORTFOLIO PRO
==============================

PROJECT STRUCTURE
- index.html
- css/style.css
- js/main.js
- assets/favicon.svg
- assets/images/  (add your photos here)

PROFILE IMAGE FIX
The website tries these extensions automatically:
  assets/images/stqrkvi.jpg
  assets/images/stqrkvi.jpeg
  assets/images/stqrkvi.png
  assets/images/stqrkvi.webp
and the same list for zero.
Preferred filenames are stqrkvi.jpg and zero.jpg.
Keep all filenames lowercase and upload images into the assets/images folder.

LOCAL TEST
1. Extract the ZIP.
2. Open this folder in VS Code.
3. Open index.html directly or use VS Code Live Server.
4. If you change photos after a previous failed load, hard-refresh with Ctrl+F5.

HOSTING
Upload the entire contents (not just index.html) into your portfolio directory:
- index.html
- css folder
- js folder
- assets folder

If publishing at https://stqrkvi.lol/portfolio/, place the files in the hosting folder mapped to /portfolio/.
Keep the folder names and relative paths unchanged.

CUSTOMIZE
- Edit copy, project descriptions, social URLs, and Discord IDs in index.html.
- Project cards describe project work and prototypes; update claims to match the current live state.
- No private keys, credentials, or visitor data are collected.
- Google Fonts are optional; local fallback fonts are included.
