# UNIQUE — Black & Pink Romantic Website

## Files
- `index.html` — page structure and content
- `style.css` — visual design, layout, responsive styles, animations
- `script.js` — language carousel, particle animation, heart burst, modal, chimes, share, and controls

## Upload
Upload all three files into your hosting folder, for example:
`public_html/unique/`

Then visit:
`https://stqrkvi.lol/unique/`

## Personalise
Open `script.js` and edit `SETTINGS.secretMessage`.
Edit the text inside `index.html` for the headline, quote, and little-things cards.

## Notes
- No backend or API keys are required.
- The optional chime is synthesised by the browser after the visitor enables it.
- Google Fonts require an internet connection; system fallback fonts are included.
- This static website's HTML/CSS/JS can be viewed by visitors through their browser.
